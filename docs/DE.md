# SHAE — Deutsche Dokumentation

## Installation
Führe `scripts/install.sh` aus, um den Go-HTTP-Server zu installieren.

## Plattform
CLI-Tool (Go-Sprache).

## Build
`go build -o shae-http-server src/main.go`

## Release
GitHub Release v0.1.0 verfügbar.
