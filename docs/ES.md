# SHAE — Documentación en Español

## Instalación
Ejecute `scripts/install.sh` para instalar el servidor HTTP en Go.

## Plataforma
Herramienta de línea de comandos (CLI) en lenguaje Go.

## Build
`go build -o shae-http-server src/main.go`

## Release
GitHub Release v0.1.0 disponible.

## Diseño
